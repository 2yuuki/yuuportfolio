Personal Work / 2024

Hoe

A high-energy event poster built through expressive type, image layering and compressed visual rhythm.

Index ↑
Type
Flash event poster
Year
2024
Role
Graphic design and visual direction
Tools / Methods
Typography, illustration and print composition

The Insight

Hoe approaches the event poster as a concentrated visual atmosphere. The composition prioritizes immediacy and personality, using dense layering to communicate the energy of a live gathering before any detail is read.

Process & Development

The final poster was developed through rapid hierarchy studies, contrast tests and production adjustments. The result balances an intentionally loud visual language with enough structure for the event information to remain legible.
